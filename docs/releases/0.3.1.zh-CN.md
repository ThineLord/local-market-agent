# Local Market Agent 0.3.1

发布日期：2026-11-09 · [English release notes](https://github.com/ThineLord/local-market-agent/blob/v0.3.1/docs/releases/0.3.1.md)

本版修复真实公开市场数据流程中的流动性读取、简报审核状态与拒绝原因显示，并用新的 Kalshi/NWS 公开样本完成全部适用阶段。真实样本仍应拒绝交易，不通过编造概率或降低门槛制造成交。

## 修复与工具

- **流动性：** 读取当前 Kalshi 顶档数量，计算双方最优卖价可买美元容量的较小值；缺失保持未知，零值保持零，非法值拒绝。旧版 cents 转换为 USD，成交量/持仓量不替代深度。
- **审核状态：** `packet-check --review` 区分来源完整性、行情/简报检查、确切审核凭据、策略可行动性、组合风险与订单审批；不再把无概率的观察简报显示为 ready。
- **拒绝原因：** 展示具体简报否决和策略/风险原因；无简报不能产生研究审核凭据。准备失败不写权益基线，执行阶段原有原子复核保持不变。
- **可重复采集：** 新增显式 `--allow-network` 的六次公开 GET 采集器，仅支持 NYC 日最高温系列，保存哈希/时间凭据及同事件有界检查，拒绝覆盖目录。自动草稿始终观察、概率为空、不生成审核或订单。

功能 PR：[#11](https://github.com/ThineLord/local-market-agent/pull/11)、[#12](https://github.com/ThineLord/local-market-agent/pull/12)、[#13](https://github.com/ThineLord/local-market-agent/pull/13)。Codex 实现；subagents 独立审查并在最终提交 CI 通过后合并，未使用 bots。

## 实际结果

市场 `KXHIGHNY-26NOV09-T57`：YES 可买容量 $1.30、NO 可买容量 $26.40，保守深度 $1.30，低于不变的 $100 默认门槛。同一真实响应在 v0.3.0 中读为未知，在 v0.3.1 中可解释计算。最终同事件六个市场均不足门槛。

六份来源和观察简报经独立 subagent 资料审核，`research_review=valid`，缺少审核的阻断已消失。NWS 点预报/观测仍无法支持校准合约概率，概率留空，策略保持观察/跳过。实际执行七步 CLI 检查：两次准备均以退出码 3 拒绝，17 张业务表前后哈希一致，零意图、审批、订单、成交或权益基线写入。行情年龄在提交时通过检查。没有虚构人工订单审批或未决市场结算。

## 验证与升级

449 项离线测试通过，1 项可选网络测试默认跳过；另显式启用后该公开网络测试通过。独立合成 15 步回归也完成审批、成交、回放和结算，不与真实样本混淆。Ruff、版本一致性和差异检查通过。

切换至 `v0.3.1` 后运行 `python -m pip install -e ".[dev]"`。本版不增加数据库或快照字段，既有封存结构保持不变。`packet-check` 仍是诊断命令：退出码 0 仅表示有效包被检查；`research_ready` 现在准确包含审核和策略条件。读取真实数据需显式网络参数，过期证据应重新采集并重新审核。
