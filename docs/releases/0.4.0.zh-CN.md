# Local Market Agent 0.4.0

发布日期：2026-11-09 · [English](https://github.com/ThineLord/local-market-agent/blob/v0.4.0/docs/releases/0.4.0.md)

本版把真实公开市场深度筛选、可复算的 NBA 概率模型和既有模拟交易流程连接起来，解决此前深度不足与缺少概率依据的瓶颈，保留全部既有风控和审批门槛。

## 更新

- 有界筛选 NBA/NFL 比赛市场，以双边最优报价的较小美元容量排序；未知、容量不足或只有旧聚合流动性数据不能通过。
- 固定 NBA Elo 模型只使用比分与主客场/中立场信息，包含保守赛果更新滞后和跨赛季回归，不用市场价格拟合概率。保留 120 份公开历史来源与哈希，检查重复赛事和赛季完整性。
- 1,230 场按时间分离的留出样本：Brier 0.209639，优于固定主场胜率基线 0.247153；logloss 0.608033 对比 0.687444；ECE 0.028186；按比赛日 bootstrap 的 Brier 差值区间 [-0.047430, -0.028255]。这是事后采集比分的预测验证，不是交易回测。
- 当前比赛证据包导入时，从原始文件重算比赛身份、合同兑付/取消条款/结算来源、报价、模型状态和保守优势；哈希正确不能替代语义校验。
- 准备、审批和执行均复查是否开赛、数据时效、模型/分箱/成本一致性及保守净优势。点估计很高或支持比例很高，都不能覆盖失败前置条件。

功能 PR：[#15](https://github.com/ThineLord/local-market-agent/pull/15)、[#16](https://github.com/ThineLord/local-market-agent/pull/16)、[#17](https://github.com/ThineLord/local-market-agent/pull/17)。Codex 实现，subagents 独立审查并在确切 head CI 通过后受 SHA 保护合并，未委派 bots。

## 实际效果

首次扫描 70 个公开 NBA 市场，31 个通过深度/报价检查，26 个精确匹配赛前比赛，2 个通过模型支持，仅选择一份证据包以避免重复敞口。模型估计 LAC 胜率 66.98%，对应留出分箱 219 场。在模拟成交价 0.481 下，扣成本的压力检查优势下界为 11.24%，高于 8% 门槛。配对 NOP 合约通过 BUY_NO 表达同一方向；报价和容量仅对应采集时点。

最终刷新扫描为 70 个市场、31 个深度/报价通过、25 个精确赛前匹配、3 个支持合约。选中的 NOP BUY_NO 证据包保守深度为 $823.7048。独立简报审核和组合风控通过后，用户明确批准确切意图；隔离账本模拟成交 $100、207.9002079 份、价格 0.481、手续费 $0.10。重复执行仍只有一笔订单/成交，内容与关联回放 `ok=true`。持仓保持未结算，等待真实赛果，未编造结算。

SAC 仍被阻断：点估计净优势约 20.69%，但保守下界只有 7.87%，不足 8%。过期数据和已开赛样例同样拒绝。最终准备/审批状态和产物见[详细验收记录](https://github.com/ThineLord/local-market-agent/blob/v0.4.0/docs/reports/0.4.0-validation.zh-CN.md)。

最后的实际界面验收发现并修复 NO 持仓误用 YES 概率估值的问题：显式市场价格统一按 YES 传入，BUY_NO 转为 1−YES；缺失报价时保持持有方向自身成本。成交本身不变。单独标记的历史回放副本将派生权益从 $10,009.0476 纠正为 $9,998.6526（未实现损益 −$1.3474），14 张非派生业务表完全不变，执行回放仍通过，原库保留。既有存储的 NO 权益/基线不会静默迁移；复用前需在独立审核的回放库中依据原始观测重建。

## 验证与升级

500 项离线测试通过，1 项网络测试默认跳过；单独启用后通过。隔离合成数据的 15 步 CLI 回归完成审批、成交、幂等重试、回放与结算；这些成交不属于公开市场实测。Ruff、版本一致性和差异检查通过。

检出 `v0.4.0` 后执行 `python -m pip install -e ".[dev]"`。无需数据库或快照结构迁移；NBA 证明放在可选证据元数据中。采集需要显式网络开关和全新输出目录，命令见[模型协议](https://github.com/ThineLord/local-market-agent/blob/v0.4.0/docs/NBA_PROBABILITY.md)。

系统仅限模拟交易。模型未纳入伤病、阵容和转会；残差迁移假设对单场比赛可能失效。两份派生分析共享 ESPN 来源，优势支持比例不是胜率，哈希不是发布方签名。当前比赛尚未结算，未编造未来赛果或公开市场结算，不宣称盈利或生产可用。
