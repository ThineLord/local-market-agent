# Local Market Agent 0.2.0

发布日期：2026-11-09 · [English release notes](https://github.com/ThineLord/local-market-agent/blob/v0.2.0/docs/releases/0.2.0.md)

本版本整理了项目入口和文件组织：提供简洁首页、分开的用户与 Agent 指南、历史文档归档，以及明确的版本、审查和发布流程。

## 更新内容

- 英文和中文首页分别介绍项目、提供离线快速启动，并按用户/Agent 分流。
- 中英文用户指南和 Agent 指南分别放入 `docs/users/` 与 `docs/agents/`。
- `docs/README.md` 索引当前说明、历史证据与版本记录。
- 根目录 `PROJECT_REVIEW.md` 移至 `docs/archive/reviews/PROJECT_REVIEW.md`；`docs/PHASE_*.md` 移至 `docs/archive/phases/`。[归档索引](https://github.com/ThineLord/local-market-agent/blob/v0.2.0/docs/archive/README.md)说明旧路径映射；历史实施日志保持原有措辞。
- 包元数据与 Python 版本常量由 `0.1.0` 提升至 `0.2.0`。CI 检查版本、首页、发布说明、变更记录与版本标签的一致性。
- 固定公开观察列表 mock 测试的时钟，避免示例关闭日期让离线测试随日历失效；运行代码的检查不变。
- Codex 统筹实现与发布；subagents 独立 review 并执行合并，不委派 bots。

## 升级方法

获取已发布代码或检出 `v0.2.0` 标签，激活 Python 3.11+ 环境，在仓库根目录运行 `python -m pip install -e ".[dev]"`。现有 `data/`、`ui/`、`src/` 与 `docs/reports/` 路径不变，无需迁移数据库或数据 schema。旧设计/审查文档的书签可按归档索引更新。

## 验证与限制

发布验证包括 Ruff、完整离线 pytest、版本/标签一致性、本地 Markdown 链接和合成观察列表快速启动。实际结果见 [IMPLEMENTATION_LOG](https://github.com/ThineLord/local-market-agent/blob/v0.2.0/docs/IMPLEMENTATION_LOG.md)。

这是实验性、仅限模拟交易的研究版本，不证明策略盈利、历史数据质量、实时数据源可用性或生产就绪。历史审查中的流程与证据限制仍需关注。独立的[账本原子性与 dry-run draft PR #4](https://github.com/ThineLord/local-market-agent/pull/4)未纳入本次发布，因此不宣称修复了那些问题。本次未增加交易逻辑、改变安全默认值、采集外部数据或调用付费模型。
