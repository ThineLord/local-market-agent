# Local Market Agent 0.5.0

发布日期：2026-11-09 · [English](https://github.com/ThineLord/local-market-agent/blob/v0.5.0/docs/releases/0.5.0.md)

新增与原有公开市场模拟流程并行的香港赛马历史回放与研究工作区。交付数据和回放基础，不宣称盈利策略已验证，不提供投注执行功能。

## 更新内容

- 有界、显式启用的 HKJC 公开采集保存赛果、出马表原文件、准确 URL、真实获取时间及 SHA-256。离线核验完整场次、全场马匹身份、正常 WIN/PLACE 派彩池完整性和赛果来源时间；退赛、退款、并头等不明确情况转人工核对。
- 区分用户报告的实际票据、未下注场、原始推荐、暂计派彩、官方规则推算的应得派彩及有凭据引用的已兑奖现金。缺证据保持 UNKNOWN，HK$10 单位派彩包含本金。
- 票数和实际下注场数分别统计；WIN/PLACE 分开显示命中率，同时提供投注额、已知结果、净收益、投注额 ROI、本金回报及逐场收盘应得权益回撤。不能据此声称场内现金回撤、票据真实性或兑奖事实已验证。
- 原始 T−10/T−3 转录保留当时已知计划赛时、完整马匹资料、此前赛绩及独立赔率；人工可用性审核绑定输入和来源哈希，保存实际审核/导入时间。缺快照、事后资料、过期赔率、身份变化和缺事前预算均有明确阻断代码。
- 描述性赛绩只统计已知名次，不把未知结果算作失败；原始概率及价值情景单独标为未验证。**所有赛马研究输出均为 NO BET，当前没有经过验证的赛马概率模型，也没有赛马下单路径。** 历史推荐保持 UNKNOWN。
- 新增独立 HKD 页面，展示历史账、完整出马名单和赛前阻断，不与原模拟盘权益相加。每次从源输入重算，不信任缓存收益。仓库只包含合成示例，私人历史记录及原快照保留本地。

功能 PR：[#20](https://github.com/ThineLord/local-market-agent/pull/20)、[#21](https://github.com/ThineLord/local-market-agent/pull/21)。Codex 实现，subagents 独立审查并在最终 head CI 通过后进行 SHA 保护合并；COMMENT 审查不是 GitHub APPROVED。未调用 bots。

## 验证与升级

完整离线测试 555 项通过，默认跳过 1 项可选网络测试；单独启用的公开只读网络测试通过。原有 15 步合成模拟流程完成审批、成交、重放和结算回归。真实公开档案成功解析一整晚 9 场、111 匹声明参赛马；浏览器实际检查历史账、全场名单、赛前阻断及旧模拟账本，控制台无错误。12 个原数据库文件哈希完全不变。私人财务记录未发布到公共仓库。

切换至 `v0.5.0` 后执行 `python -m pip install -e ".[dev]"` 安装新增 Beautiful Soup 解析依赖。无数据库迁移、旧市场删除、订单重新批准或事后补造模拟成交。采集需显式启用网络并指定新输出目录。

```sh
PYTHONPATH=src python scripts/horse_replay.py research --input data/fixtures/horse_research --output data/reports/horse-synthetic
python ui/server.py --horse-workspace data/horse --port 8510
```

格式与使用见[中文赛马指南](https://github.com/ThineLord/local-market-agent/blob/v0.5.0/docs/HORSE_REPLAY.zh-CN.md)和[English guide](https://github.com/ThineLord/local-market-agent/blob/v0.5.0/docs/HORSE_REPLAY.md)。合成示例仍为 NO BET；页面需要另行提供本地记录与来源。

## 尚存边界

事后官方档案不能替代原始赛前快照。人工审核与哈希绑定审查过程，不能密码学证明历史可用性或独立认证转录正确性。原快照位置及兑奖凭据仍待外部提供，没有虚构赔率、概率或理由。单晚、少量且同场相关的票据不能证明稳定预测优势；概率校准需要有依据的原始概率序列和独立验证方案，当前 UNKNOWN。原市场风控及逐意图审批要求不变。
