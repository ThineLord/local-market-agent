# Local Market Agent 0.5.0

Released: 2026-11-09 · [简体中文](https://github.com/ThineLord/local-market-agent/blob/v0.5.0/docs/releases/0.5.0.zh-CN.md)

Adds a separate Hong Kong racing research and historical replay workspace alongside the existing public-market paper workflows. It is a data/replay foundation, not a validated profitable strategy or a betting execution service.

## Changes

- Bounded, explicit public HKJC acquisition preserves raw result/declaration files, exact URLs, actual retrieval times and SHA-256 receipts. Offline imports verify complete meetings, full-field horse identities, ordinary WIN/PLACE pool completeness and final-result chronology. Ambiguous withdrawals, refunds and dead heats require manual review.
- Historical records distinguish reported actual tickets, unbet races, original recommendations, provisional gross returns, official rule-based entitlements and document-referenced redeemed cash. Missing evidence stays UNKNOWN. Official dividends include the HK$10 unit stake.
- Metrics separate tickets from bet races and WIN from PLACE: stake, known outcomes, hit rate, net entitlement, stake ROI, bankroll return and race-close entitlement drawdown. They do not assert intrarace cash drawdown, verified ticket ownership or cash redemption.
- Original T−10/T−3 transcription inputs retain the schedule known then, full fields, earlier form and separate indicative odds. Source-bound manual availability reviews retain actual review/import times. Missing checkpoints, hindsight data, stale odds, field changes and unproven precommitted budgets produce explicit blocking reasons.
- Descriptive form comparisons count only known finishes; unknown outcomes never become losses. Imported original probabilities and illustrative value scenarios are clearly unvalidated. **Every racing research result is NO BET: no racing probability model has been validated and no racing order path exists.** Historical recommendations remain UNKNOWN.
- The optional read-only dashboard shows HKD history, all declared runners and pre-race blockers without aggregating them into existing paper portfolio balances. It recomputes from verified source inputs rather than trusting saved derived totals. Public fixtures are synthetic; private histories and raw snapshots remain local.

Functional PRs: [#20](https://github.com/ThineLord/local-market-agent/pull/20) and [#21](https://github.com/ThineLord/local-market-agent/pull/21). Codex implemented; subagents performed independent advisory reviews and guarded merges after exact-head CI. These COMMENT reviews are not GitHub APPROVED reviews. No bots were used.

## Validation and upgrade

555 offline tests passed, one optional network test skipped by default; the separately enabled read-only public network test passed. The existing synthetic 15-step workflow completed its approval, fill, replay and settlement regression. Real public replay parsed one complete nine-race meeting with 111 declared runners. Browser checks exercised the historical ledger, full field, research blockers and existing paper ledger with zero console errors. Twelve pre-existing database file hashes remained unchanged. User-specific financial history is not published in this repository.

Check out `v0.5.0` and run `python -m pip install -e ".[dev]"` to install the additional Beautiful Soup HTML parser dependency. No trading database migration, old-market deletion, order reapproval or retrospective paper fill occurs. The new collector is network opt-in and requires a new output directory.

```sh
PYTHONPATH=src python scripts/horse_replay.py research --input data/fixtures/horse_research --output data/reports/horse-synthetic
python ui/server.py --horse-workspace data/horse --port 8510
```

See the [English racing guide](https://github.com/ThineLord/local-market-agent/blob/v0.5.0/docs/HORSE_REPLAY.md) and [Chinese guide](https://github.com/ThineLord/local-market-agent/blob/v0.5.0/docs/HORSE_REPLAY.zh-CN.md) for record and checkpoint formats. The synthetic import remains NO BET. The dashboard needs separately supplied local records and sources.

## Limits

Retrospective official archives cannot substitute for original pre-race snapshots. Human review and checksums bind inputs but do not cryptographically prove historical availability or independently authenticate a transcript. Original snapshot locations and redemption evidence remain external prerequisites; no missing odds, probabilities or reasoning were fabricated. One meeting and correlated tickets cannot establish predictive advantage. Calibration remains UNKNOWN without a defensible original probability series and a separately specified evaluation protocol. Existing paper risk and per-intent approval gates are unchanged.
