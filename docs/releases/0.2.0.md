# Local Market Agent 0.2.0

Release date: 2026-11-09 · [中文发布说明](0.2.0.zh-CN.md)

This release makes the repository easier to enter and maintain: concise project homepages, separate user and Agent guides, organized historical documentation, and an explicit version/review/release workflow.

## Changes

- English and Chinese homepages introduce the project, give an offline quick start, and route readers by role.
- User and Agent guides are split by language under `docs/users/` and `docs/agents/`.
- `docs/README.md` indexes current references, historical evidence, and version notes.
- `PROJECT_REVIEW.md` moves to `docs/archive/reviews/PROJECT_REVIEW.md`; `docs/PHASE_*.md` moves to `docs/archive/phases/`. The [archive index](../archive/README.md) explains old paths. Historical implementation-log entries retain their original wording.
- Package metadata and the Python version constant move from `0.1.0` to `0.2.0`. CI checks matching versions, homepages, release notes, changelog, and version tags.
- Fixed the mocked public-watchlist test clock so the fixture closing date cannot make offline validation depend on the real calendar; runtime checks are unchanged.
- Codex coordinates implementation and publishing; subagents independently review and merge. No bot delegation is used.

## Upgrade

Pull the released code or check out tag `v0.2.0`, activate a Python 3.11+ environment, and run `python -m pip install -e ".[dev]"` from the repository root. Existing `data/`, `ui/`, `src/`, and `docs/reports/` paths remain unchanged. No database or data-schema migration is required. Update bookmarks to moved design/review files using the archive index.

## Validation and limits

Release validation includes Ruff, the offline pytest suite, version/tag consistency, local Markdown links, and the synthetic watchlist quick start. Exact observed results are recorded in [IMPLEMENTATION_LOG](../IMPLEMENTATION_LOG.md).

This is an experimental, paper-only research release. It does not establish strategy profitability, historical-data quality, live-provider availability, or production readiness. Known workflow and evidence limitations in historical audits remain relevant. The separate [draft ledger atomicity and dry-run PR #4](https://github.com/ThineLord/local-market-agent/pull/4) is excluded; this release does not claim those fixes. No trading logic, safety defaults, external data collection, or paid model calls are added.
