# Local Market Agent 0.3.1

Released: 2026-11-09 · [简体中文](https://github.com/ThineLord/local-market-agent/blob/v0.3.1/docs/releases/0.3.1.zh-CN.md)

This patch fixes public-market liquidity normalization, misleading brief-review readiness, and opaque preparation refusals. A fresh Kalshi/NWS sample completed every applicable stage and correctly remained blocked; neither estimates nor approvals were invented to manufacture a fill.

## Changes

- Normalize current Kalshi best-quote sizes to conservative USD buy capacity: the smaller of YES ask × ask size and (1 − YES bid) × bid size. Preserve missing/zero depth, reject invalid sizes, convert legacy cents, and never substitute volume/open interest.
- Add optional `packet-check --review` and separate source integrity, market/brief checks, exact review validity, strategy actionability, portfolio risk, and order approval. Observation briefs without a probability no longer appear ready.
- Reject research reviews without a brief; expose actual research/strategy/risk vetoes. Rejected preparation no longer writes equity baselines; execution retains atomic risk/equity rechecks.
- Add a six-GET, opt-in public NYC daily-high collector with new-directory isolation, checksummed source receipts and a bounded same-event scan. Its draft is always observation-only with null probability; it creates no review, approval, database or settlement.

Functional PRs: [#11](https://github.com/ThineLord/local-market-agent/pull/11), [#12](https://github.com/ThineLord/local-market-agent/pull/12), [#13](https://github.com/ThineLord/local-market-agent/pull/13). Codex implemented; independent subagents reviewed and merged after exact-head CI. No bots were delegated work.

## Actual acceptance

`KXHIGHNY-26NOV09-T57` had $1.30 YES and $26.40 NO best-ask capacity; conservative depth was $1.30 versus the unchanged $100 minimum. The identical captured response read as unknown under v0.3.0 and becomes explainable under v0.3.1. All six markets in the final same-event scan remained below the minimum.

An independent subagent checked six source receipts and the observation brief. The exact research review became valid, removing the missing-review blocker. NWS point values still do not establish a calibrated contract probability. Seven CLI checks included two rejected preparation attempts (exit 3); all 17 business tables retained identical before/after hashes. No intent, approval, order, fill or equity baseline was created. Freshness passed at submission. No human approval or unresolved-market settlement was fabricated.

## Validation and upgrade

449 offline tests passed; one optional network test was skipped by default and passed when separately enabled. The separate synthetic 15-step regression completed approval, execution, replay and settlement; those fills are not public-market results. Ruff, release consistency and diff checks passed.

Check out `v0.3.1`, then run `python -m pip install -e ".[dev]"`. No database/snapshot fields were added, preserving existing sealed input shapes. Diagnostic `packet-check` exit 0 still means a valid packet was inspected; `research_ready` now accurately includes review and strategy conditions. Public collection requires explicit network opt-in; stale inputs need fresh collection and review.
