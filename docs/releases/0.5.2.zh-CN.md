# Local Market Agent 0.5.2

2026-11-26 · [English](https://github.com/ThineLord/local-market-agent/blob/v0.5.2/docs/releases/0.5.2.md)

本补丁汇总 PR #24–#32，修正模拟成交的报告和回放、历史证据校验，以及公开市场数据解析。

- **模拟下单与审计。** 有可核验成交回执时，重复执行会返回原订单，后续报价或结算均不会产生重复成交。多个意图共用信号时，状态页标出实际成交的意图。旧账本缺少区分它们的回执时，显示 `unavailable`，并提供 `paper-status` 查询。日报对开仓手续费和各笔平仓成交费各计一次。即使原风控决定已超出近期活动列表，仪表盘仍能沿订单找到它。
- **只读查询。** `workflow-status`、`paper-status` 和 `paper-replay` 可检查不完整的账本或尚不存在的路径，查询不会创建或迁移数据库。快照查询和按时间排序的 JSONL 导出会计入原始时间戳的 UTC 偏移。
- **证据与历史报告。** 已保存的观察列表简报会校验证据标识和时间顺序。历史回放在结算结果公开前采用观测时的市场状态，开放的市场可正常通过这项预检。历史日报只纳入截至报告时点已可见的记录。所选市场的数据符合条件且结算可信时，报告才会将结果列为模拟盈亏证据。
- **公开数据与赛马。** 公开数据适配器修正了缺失市场标识、带引号标签、搜索编码、无效价格和分页游标的处理，并保留零报价。赛马回放会保留可结算的票据；同场其他票据状态未知时，全场回报仍待定。赛马研究继续输出 NO BET。

在仓库根目录执行 `git pull --ff-only`，再执行 `python -m pip install -e ".[dev]"` 即可升级。既有账本无需迁移。读取工作流状态的程序应能处理旧记录归属不明时的 `unavailable`。普通模拟订单仍须逐意图审批。各项修复详见[变更日志](https://github.com/ThineLord/local-market-agent/blob/v0.5.2/docs/CHANGELOG.md)。
