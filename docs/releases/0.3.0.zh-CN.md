# Local Market Agent 0.3.0

发布日期：2026-11-09 · [English release notes](https://github.com/ThineLord/local-market-agent/blob/v0.3.0/docs/releases/0.3.0.md)

本版落实 P1–P3 流程提升：模拟执行必须经过绑定具体内容的意图审批，证据到结算的完整链路可在本地实际演示。

## 更新

- 开仓/平仓原子化、重试幂等；每日和批量 dry-run 使用可丢弃的数据库副本。
- 筛选和执行共享硬性检查，保留行情时间，使用 UTC 日初权益与有效观察峰值计算亏损/回撤；无效行情不污染基线，其他持仓也必须有新鲜报价。
- 逐意图审批记录审核人标签、理由、有效期和拒绝历史。执行复查与成交写入共用事务；公开数据运行不能关闭审批。
- 回放检查内容哈希和完整开仓关联，正常平仓仍可回放；旧版未封存记录明确提示限制。
- CLI 以 JSON 和退出码区分完成、拒绝、待审批、熔断和失败，无效数据与含拒绝日期的沙盒批次不再返回笼统成功。
- 证据包绑定来源文件、时间、研究简报与明确审核；结算来源审核和模拟平仓有原子化凭据。
- 新增 15 步隔离合成演示；只读首页展示版本、观察时间、阻断原因和可复制的下一步命令。

## 升级与迁移

使用 Python 3.11+，切换至 `v0.3.0` 后运行 `python -m pip install -e ".[dev]"`。使用新版本打开已有数据库前保留独立备份。正常初始化会添加权益基线、意图、审批、执行和结算表，不改写旧记录；仪表板只读打开数据库。回溯模拟使用独立数据库；演示命令拒绝覆盖已有输出目录。

`paper-log` 改为生成待审批意图。随后使用 `paper-status`、`paper-approve`、`paper-execute`、`paper-replay`。脚本需处理退出码：0 完成/预演/批准，1 失败，2 参数或数据无效，3 拒绝，4 待审批，5 熔断。沙盒按失败、熔断、拒绝、待审批的优先级汇总。静态旧示例属于历史数据，今天被拒绝可能是正确结果；完整当前时间演示使用：

```bash
python scripts/demo_workflow.py --output data/reports/workflow-demo
LMA_DB_PATH=data/reports/workflow-demo/demo.sqlite python ui/server.py --port 8503
```

## 验证与限制

最终功能测试为 433 项通过、1 项可选网络测试跳过；Ruff、版本、JavaScript 语法和差异检查通过。真实浏览器验证了桌面、移动端和复制命令。CLI 实际完成待审批 → 批准 → 成交 → 重试 → 回放 → 结算 → 回放，只产生一笔开仓成交和一笔平仓成交。

小规模 Kalshi/NWS 公开样本通过来源校验，但仍因缺少流动性和已审核简报而阻断。没有补造概率估计、公开市场审批或盈利结果。NWS 数据仅作研究支持，该市场规则指定的结算来源是 The Weather Company。

项目仍是仅限模拟交易的实验软件。审核人名称是可信本地标签，不提供身份认证；哈希不是签名，回放不重新运行模型/策略。峰值仅代表有效观察峰值，日初权益采用上一个 UTC 交易日最后的有效观察值。不增加实盘能力或付费模型调用，不声称盈利或生产可用。
