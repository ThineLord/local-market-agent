For current behavior use the [user guide](../users/README.md), [technical references](../README.md) and [release notes](../releases/). Existing absolute links to earlier release tags remain valid. A clone can inspect any archived file with `git show v0.5.0:docs/path/to/file.md`.

Runtime code, fixtures and local market databases were not moved. The legacy [report directory](../reports/README.md) retains one input used by an existing command; generated reports stay local.
