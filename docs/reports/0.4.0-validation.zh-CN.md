# 0.4.0 真实公开市场与概率验收

日期：2026-11-09（香港时间）。Codex 实现；subagents 独立代码/来源审查及合并。仅使用公开只读接口、隔离模拟账本；未调用 bots、实盘/私有交易接口或付费模型，未修改用户已有数据库。

## 实现与证据

| 问题 | 本版处理 | 保留的阻断 |
| --- | --- | --- |
| 原天气样本真实深度不足 | 有界筛选公开 NBA/NFL 比赛市场，按顶档双边较小美元容量排序 | 缺失、聚合旧值或低于 $100 均拒绝 |
| 缺少可辩护概率 | 冻结自定义 NBA Elo；完整赛季来源、时间分离留出评分与分箱残差压力检查 | 验证失败、样本不足、保守净优势不足拒绝 |
| 分析通过不一定约束执行 | 将 NBA 门槛接入准备、审批、执行；导入时从原始来源复算 | 已开赛、报价/事件状态过期、历史源过期拒绝 |
| 来源哈希不能证明合同语义 | 精确匹配赛事、球队、主客场、合同、单位兑付、取消条款和结算机构 | 更改源并同步哈希仍不能绕过复算与语义校验 |

代码功能 PR：[#15](https://github.com/ThineLord/local-market-agent/pull/15)、[#16](https://github.com/ThineLord/local-market-agent/pull/16)、[#17](https://github.com/ThineLord/local-market-agent/pull/17)。独立审查发现并修复：聚合流动性错误准入、终场记录晚于对应来源时间、导入未重验关键合同前置条件。最终 exact-head CI 通过后由 subagent 合并。审查记录是实际 subagent/advisory review，不冒称同账户 GitHub APPROVED。

未降低深度 $100、spread 0.08、edge `max(0.08,2×spread)`、300 秒行情时效、证据/置信度、组合风控或人工审批要求。新增当前赛季来源最长六小时与赛前限定，不通过刷新分析时钟刷新原始数据。无数据库或快照字段迁移。

## 冻结模型和验证

协议在下载结果前冻结，参数未按留出或市场价格调优。初值 1500、K=20、尺度400、主场优势65、赛季保留75%；赛果在开赛日期后第二个 UTC 日起用于后续预测。训练期为赛季2024/2025，留出2026，当前2027。详见[协议与复现命令](../NBA_PROBABILITY.md)。

120 个 ESPN 球队/赛季公开端点全部成功。三个完整历史赛季各 1,230 场，每队82场；训练2,460场，留出1,230场，当前赛季139场已终场。保留原始文件、URL、真实采集时间、哈希、赛季覆盖、去重与排除原因。历史比分为事后采集，不是当时信息可得性的交易回测。

| 指标 | 固定 Elo | 固定训练期主场胜率基线 |
| --- | ---: | ---: |
| Brier（越低越好） | 0.209639 | 0.247153 |
| Logloss（越低越好） | 0.608033 | 0.687444 |
| 10-bin ECE | 0.028186 | 未用于该门槛 |

按比赛日成块 bootstrap 的配对 Brier 差值95%区间为 [-0.047430, -0.028255]，满足预先声明门槛。独立 subagent 复算一致。分箱残差只做当前候选压力诊断，不冒称在同一留出上重新训练并独立验证的新模型。`confidence=0.999` 是1,000次重采样中999次净优势达标的比例，不是99.9%胜率。

## 用户审批与真实模拟执行

本地隔离路径：`data/reports/v0.4.0-validation/public-execution/`，账本为其中`paper.sqlite`。原始公开响应、DB、完整凭据与截图只留本地忽略目录。

1. `packet-check --review` 返回有效且研究就绪；组合风控通过，`packet-prepare` 返回4（待审批）。
2. 未审批时执行返回4，订单/成交/审批/持仓全为0。
3. 向用户展示确切意图、市场、方向、$100本金、数量、报价、模拟成交价、手续费、模型与门槛。用户明确回复“批准这份模拟订单”。
4. 20:03:18.608621 UTC记录该意图批准；20:03:23.536096 UTC在原始时效窗口内执行成功。报价年龄约160秒、事件状态约168秒，均低于300秒。未回填时间或放宽门槛。
5. 重复执行返回原订单，不重复成交。`paper-replay` 内容哈希和关联校验 `ok=true`，无错误。生成日报与工作流状态。
